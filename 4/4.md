我阅读这四个文件后，这个五子棋程序的整体实现思路可以按“模块划分 → 启动流程 → 主循环 → 落子与胜负 → 界面交互”来梳理。

## 1. 总体设计：逻辑与界面分离

程序分成三个部分：

- `game.h / game.c`：负责五子棋的**纯游戏逻辑**，包括棋盘数据、当前玩家、落子、合法性判断、胜负判断、切换玩家。
- `console.h / console.c`：负责 **Windows 控制台界面**，包括初始化控制台、清屏、画棋盘、移动光标、显示赢家/平局/中断信息。
- `main.c`：负责**流程控制**，把游戏逻辑和界面串起来，处理开始、主循环、按键、结束。

棋盘大小是 `9×9`，获胜条件是 `WIN_LENGTH = 5`，空格用 `' '` 表示，玩家是 `'X'` 和 `'O'`。

## 2. 启动与初始化

程序从 `main` 开始：

1. 声明 `Console console` 和 `Game game`。
2. 调用 `initConsole(&console)`：
   - 设置窗口标题为 `Chess`。
   - 设置控制台大小 `60 列 × 30 行`。
   - 获取标准输入/输出句柄。
   - 设置光标大小 `dwSize = 100`，让光标显示成一个方块。
3. 调用 `initGame(&game)`：
   - 把 `cells` 全部初始化为空格。
   - 当前玩家设为 `'X'`。
   - 光标坐标设为 `(0,0)`。
   - 步数 `move_count = 0`。
4. 输出提示：`Press q to exit, press s to start`。
5. 轮询按键，按 `S` 开始，按 `Q` 退出。
6. 开始后 `clearBoard` 清屏，进入游戏循环。

## 3. 主循环与按键处理

主循环中，先调用 `printBoard` 画出棋盘，再调用 `freshPos` 把控制台光标移动到当前游戏坐标对应的棋盘格上。

然后进入内层按键循环，用宏：

```
#define IF_PRESS(VK) ((GetAsyncKeyState(VK))&1)
```

检测按键“刚按下”的瞬间。主要处理：

- `Q`：中断游戏，打印中断信息并退出。
- 空格：尝试落子。
- `W/A/S/D`：移动游戏光标，同时移动控制台光标。

`GetAsyncKeyState` 不需要阻塞等待输入，所以可以实时响应方向键移动。

## 4. 棋盘绘制与坐标映射

`printBoard` 用字符画出棋盘。每个格子宽约 2 个字符，所以棋盘看起来是：

text

```
__ __ __ ...
|  |  |  |
__ __ __ ...
|  |  |  |
...
```



游戏逻辑坐标 `(x, y)` 中，`x` 是列，`y` 是行。要把它映射到控制台字符坐标，用了两个函数：

c

```
int translateGameCursorPosX(int x) { return 2*x + 1; }
int translateGameCursorPosY(int y) { return 2*y + 1; }
```



因为每一列棋子字符前面有一个 `|`，所以列坐标是 `2*x+1`；每一行棋子上面有一条横线，所以行坐标是 `2*y+1`。

`freshPos` 就是根据当前 `game->x` 和 `game->y`，把控制台光标定位到对应格子上。

## 5. 落子逻辑

按空格时：

1. 用 `judgeIfValidCell` 检查坐标是否越界、该格是否为空。
2. 如果合法，调用 `put` 把当前玩家写入 `cells[x][y]`。
3. `move_count++`。
4. 清屏、重画棋盘、重新定位光标。
5. 判断是否胜利：`judgeIfWin`。
6. 如果没赢，判断是否平局：`move_count >= BOARD_SIZE * BOARD_SIZE`。
7. 如果都没结束，调用 `changePlayer` 切换玩家。

## 6. 胜负判断

胜负判断在 `game.c` 中，核心是四个方向：

- `judgeRow`：水平方向，检查 `(x,y)` 向右连续 5 个。
- `judgeCol`：垂直方向，检查 `(x,y)` 向下连续 5 个。
- `judgeDiag`：主对角线，检查 `(x,y)` 向右下连续 5 个。
- `judgeDiag1`：副对角线，检查 `(x,y)` 向右上连续 5 个。

每个函数都会先检查边界，防止越界；再检查起点不是空格；然后逐个比较后续格子是否与起点相同。

`judgeIfWin` 双重循环遍历整个棋盘，只要任意一个起点在任意方向形成五连，就返回 1。因为遍历了所有起点，所以不需要反向再检查一遍。

## 7. 结束处理

- 如果胜利，`goto A`，调用 `printWinner` 打印当前玩家是赢家。此时还没有切换玩家，所以 `game.current_player` 就是赢家。
- 如果平局，`goto B`，调用 `printDraw` 打印无赢家。
- 如果按 `Q` 中断，调用 `interrupt` 打印中断信息。
- 最后都等待按 `Q` 退出，并关闭控制台句柄。
